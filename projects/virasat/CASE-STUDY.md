# VIRASAT — Premium Streetwear Shopping Experience

## Project Overview

VIRASAT is a premium fashion shopping experience designed in Figma for a contemporary streetwear brand. The design covers the complete shopping journey from discovery to checkout.

## My Role

**UI/UX Designer — Mohammad Shoaib**

## Design Tool

**Figma**

## Screens Designed

- Home page
- Shop / product listing
- New arrivals
- Product details
- Men's wear
- Women's accessories
- Men's accessories
- Discount / sale
- Mini cart
- Main cart
- Checkout
- Sign up
- Profile
- Favorites
- Search

## Core User Flow

**Home → Shop → Product Details → Add to Cart → Mini Cart → Main Cart → Checkout**

Supporting journeys include search, favorites, profile, category browsing, new arrivals, and sale discovery.

## UX Focus

- Clear product discovery
- Strong category navigation
- Consistent shopping flow
- Product-focused information hierarchy
- Easy cart and checkout progression
- Premium visual presentation

## Visual Design

The interface uses a fashion-focused visual direction with large product presentation, structured sections, strong typography, and consistent spacing across the shopping experience.

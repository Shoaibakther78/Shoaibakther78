# VIRASAT — Premium Streetwear Brand App

## Overview
VIRASAT is a premium streetwear mobile app concept focused on creating a clean, modern shopping experience for a contemporary fashion brand.

## Role
**UI/UX Designer — Mohammad Shoaib**

## Design Focus
- Mobile-first user experience
- Product discovery and browsing
- Product detail experience
- Clear visual hierarchy
- Premium streetwear visual language
- High-fidelity UI and prototyping in Figma

## Process
1. Defined the shopping experience and user flow
2. Structured the main app screens
3. Created wireframes and refined layouts
4. Designed the visual system and high-fidelity screens
5. Built an interactive prototype in Figma

## Tools
**Figma · UI Design · UX Design · Wireframing · Prototyping**

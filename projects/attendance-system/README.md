# Student Attendance System

## Overview
A web application concept for recording and managing student attendance with a simple, user-friendly workflow.

## Planned Features
- Student registration
- Attendance marking
- QR-based attendance workflow
- Attendance history
- Simple dashboard and records

## Technology Direction
**Java / Web Technologies**

## Project Goal
To create a faster and more organized attendance experience while reducing manual record keeping.
